# 回放页面板操作

回放页面板直接支持拖拽停靠、标签分组、分隔线缩放和关闭。面板开启入口统一放在“设置 → 回放面板”，回放页不再放置面板菜单、工作区菜单或右键移动菜单。

## 拖拽

- 拖动面板名称：移动单个面板。放到目标区域中央合并为标签；放到四边拆成相邻面板。
- 拖到工作区最外侧边缘：沿整个工作区边缘停靠，可以跨越原有多个区域。
- 拖到标签栏：按指针位置插入标签，支持组内排序及跨组插入。
- 拖动标题栏左侧的 `⠿`：移动整个标签组。
- 拖走一个区域的最后一个面板后，原区域自动收起，相邻区域补齐。
- 拖动时显示落点预览；Esc、切换窗口或在工作区外释放可取消。

## 缩放

拖动面板间的共享分隔线，一侧增加时另一侧减少。同一分区内的子面板随分区调整。窗口尺寸改变时，优先在可用空间内分配各面板的最小尺寸，不因保存的旧比例把整块画布撑大。只有全部面板的最小尺寸总和确实超过窗口时才出现工作区滚动条。双击分隔线恢复该分区的默认比例。

## 关闭与开启

- 点击标签上的 `×` 关闭面板；关闭最后一个标签时，该区域自动收起。
- 到“设置 → 回放面板”勾选需要的面板重新开启；取消勾选也可关闭。重新开启优先回到相关面板旁或原标签位置；相关区域也被关闭时寻找仍可用的邻接区域。关闭不删除 REP、书签或分析数据。
- 全部关闭时保留一个空白区域，提示去设置开启。
- 旧配置中遗留的空区域在载入时自动收起。

布局、当前标签和开关状态自动保存。Ctrl+Z / Ctrl+Y 可撤销、重做布局操作，文本输入框保留自身编辑快捷键。原有命名工作区配置保留，不提供回放页菜单入口。

采集、定位、接管和切换回放期间暂时禁止调整布局。面板移动及标签切换继续使用原业务视图和游戏窗口宿主。
