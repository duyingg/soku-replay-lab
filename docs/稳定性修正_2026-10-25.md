# 稳定性修正与回归记录

日期：2026-10-25（北京时间）。用户本轮明确要求检查程序并优化。

## 修正

- 拖放松手时重新读取当前位置并计算落点，避免使用上次预览的位置提交。
- 关闭独立面板时记忆邻接面板及方向；关闭组内标签时记忆同组面板和标签次序。记忆随布局保存，重新开启优先使用该关系；邻接面板也关闭时有循环保护和可用区域回退。
- 旧坐标迁移单独生成当前布局，默认布局从默认规则生成，避免把历史调整结果当作默认布局。
- 在页面挂载前完成面板注册，并保存初始布局。页面回归在加入注册保存后暴露空引用：旧实例的加载回调可能读取刚创建的新实例。回调现绑定自己的工作区，过期实例不能覆盖当前布局或默认布局。
- 游戏宿主异步调整期间若收到新的尺寸，完成后立即继续调整到最终尺寸，不再仅等待探针定时刷新。
- 无效的面板重开记忆不会导致整个有效布局失效；允许兼容没有新增记忆字段的旧配置。

保持回放页无面板菜单，开启入口仍为“设置 → 回放面板”。不改原生协议、游戏资源及其他业务规则。
