# 非面板功能逻辑检查

日期：2026-10-25（北京时间）。本轮检查样本管理、导入、统计筛选／导出、逃压批次及技能分支播放返回，不调整面板交互。

## 已修复

1. 查看技能分支时，“移除当前”原先按技能 REP 路径匹配，不能移除对应的原始分析样本。现在按原样本匹配，并规范化路径比较。
2. 移除样本时原先先删列表再载入替代样本；替代文件失效会留下不在列表中的当前会话。现在确认替代样本载入后才删除原样本，导入失败保留现有会话和列表。
3. 新样本不包含之前选中的统计回合时，回合筛选恢复“全部”，避免看起来整份统计消失。新样本仍包含该回合时保留选择。
4. 移除最后一份／清空样本时，按探针实时状态决定释放回放，不依赖可能为空或滞后的界面状态缓存。
5. 逃压只防御对照同样检查起点、观察范围、结束索引与完整输入验证，证据不足则“未判定”，不能用于生成成功建议。
6. 攻击试验结束后若收到停止请求，不再追加新的只防御对照；原回放恢复流程仍执行。
7. 技能分支载入失败且原回放恢复也失败时，清除原生 REP 绑定，避免继续信任已失效的绑定关系。
